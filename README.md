# Mini-Dataset-Analyzer

A simple Python project that analyzes a numerical dataset and provides useful information such as average, minimum, maximum, sorted values, and unique values.

## Features

- Displays total values and sum of the dataset
- Calculates average, minimum, and maximum
- Sorts dataset values
- Identifies unique values
- Searches for a specific value
- Counts how many times a value appears
- Python 3.x

## Setup

1. Clone the repo:

   `git clone https://github.com/Jagritithandel/Mini-Dataset-Analyzer.git`

2. Open the project folder:

   `cd Mini-Dataset-Analyzer`

3. Run the program:

   `python dataset_analyzer.py`
